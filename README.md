# Personal Portfolio Website

This is a simple personal portfolio website built using **HTML and CSS**. It presents my profile, interests, projects, and contact information through a clean and simple design.

## Pages

* **Home Page** – Contains my introduction, About Me section, interests, projects, and social media links.
* **Contact Page** – Contains a contact form where visitors can enter their name, email, and message.

## Live Website

https://inthusha20241647-commits.github.io/profile-simple-website/

## Technologies Used

* HTML5
* CSS3
* Google Fonts

## Features

* Simple and clean portfolio design
* About Me section
* Interests section
* Projects showcase
* Social media links
* Contact form
* Separate Home and Contact pages
* Custom CSS styling

## Purpose

This project was created to practise the fundamentals of **HTML and CSS** .
