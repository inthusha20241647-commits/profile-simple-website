# 👩‍💻 Personal Portfolio Website

This is a simple portfolio-style website built using HTML and CSS. It demonstrates a clean and simple design with sample profile information, interests, projects, and contact sections.

## 📄 Pages

* 🏠 **Home Page** – Contains introduction part, About Me section, interests, projects, and social media links.
* 📧 **Contact Page** – Contains a contact form where visitors can enter their name, email, and message.

* 🎨 CSS3
* 🔤 Google Fonts

* 🎯 Simple and clean portfolio design
* 👤 About Me section
* ❤️ Interests section
* 💼 Projects showcase
* 🔗 Social media links
* 📝 Contact form
* 📑 Separate Home and Contact pages
